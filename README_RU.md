# FurryOS 1.0 — проект лаунчера для Samsung Galaxy A02

Это исходный проект Android-лаунчера, рассчитанный на Android 11 и выше.
Это **не прошивка** и не заменяет Android: приложение можно выбрать приложением
главного экрана (Home app).

## Что уже есть
- минималистичный пастельно-лиловый домашний экран;
- часы и дата;
- быстрые ярлыки телефона, браузера и настроек;
- меню установленных приложений с поиском;
- лёгкий интерфейс без тяжёлых анимаций и сторонних библиотек.

## Как собрать APK
1. Открой проект в Android Studio (Hedgehog или новее).
2. Дождись синхронизации Gradle.
3. Выбери **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
5. Передай APK на Samsung A02 и установи. Если Android спросит, разреши установку
   приложений из выбранного источника.
6. Нажми Home и выбери FurryOS как главный экран.

Параметры: minSdk 23, targetSdk 30, compileSdk 35.
Для сборки требуется Android SDK Platform 35 и Android Gradle Plugin 8.6.1.
